#  Simulação de Veículos (Java)

Sistema desenvolvido em Java para simular o comportamento e o gerenciamento de veículos, aplicando conceitos de POO.

##  Funcionalidades
* Modelagem de classes de veículos.
* Manipulação de atributos e métodos específicos.
* Interface integrada via NetBeans.

##  Estrutura do Projeto
O código fonte principal reside na pasta `SistemaVeiculos/src`.

##  Requisitos
* Java JDK 17 ou superior.
* IDE NetBeans ou VS Code com extensões Java.
